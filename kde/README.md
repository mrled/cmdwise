# KDE

Modern KDE is a good foundation for a cmdwise desktop because it is extensively configurable, and comes with a bunch of apps that all work together and can be configured together.

KDE system-wide shortcuts are set in System Settings -> Keyboard -> Shortcuts. This includes desktop-wide shortcuts that are handled by the window manager such as launching apps with keystrokes or maximizing windows, and common shortcuts for KDE native apps such as copy, paste, and undo. KDE native apps have a separate per-app way to set shortcuts with app-specific functionality like making text bold or changing view options. The split isn't perfect; some stuff like File -> New is handled in the system-wide settings, while File -> New Window is considered app-specific and must be configured separately per app.
