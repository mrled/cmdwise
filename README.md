# cmdwise

Apple Unix variants --- macOS, Mac OS X, and even A/UX --- have a keyboarding advantage that Linux graphical environments have so far refused to copy: the command key. This is really too bad, because it's a key that is dedicated for GUI operations, and gives terminals and text editors full use of ctrl and alt keys.

There is no reason to remember that your terminal needs ctrl-shift-x/c/v for cut/copy/paste. If your environment used cmd-x/c/v for these functions instead, you'd have consistency everywhere.

This also would allow text fields to support Emacs keybindings even in other apps, like ctrl-a/e for beginning/end of line, or alt-b/f for backward/forward word.
